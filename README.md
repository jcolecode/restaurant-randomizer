# FoodieFynd

FoodieFynd is a restaurant randomizer that helps users discover new dining spots. Features include:
- Customizing search distance to find nearby restaurants
- Choosing specific types of cuisine
- Providing additional restaurant recommendations based on the user’s preferences

![Demo](https://github.com/jcolecode/restaurant-randomizer/blob/main/demo.png?raw=true) </br>
[Visit FoodieFynd](https://www.foodiefynd.com)

## Inspiration
As a self-proclaimed foodie, I often struggle with deciding where to eat. I built FoodieFynd to simplify this decision-making process for myself and others.

## How it works
Users select a preferred distance and type of cuisine. FoodieFynd then returns a random restaurant, along with additional suggestions that match the search criteria.

## Development
The frontend was built using React and Bootstrap, while the backend consists of Node.js, Express.js, Google Places API, and Firebase Functions. Deployment was managed via Firebase, and several third-party libraries were integrated to enhance performance.

## Challenges
Learning to work with the Google Places API presented some initial hurdles, leading to time-consuming bugs. However, troubleshooting these issues greatly expanded my skills.

## Lessons learned
FoodieFynd provided me with hands-on experience in frontend design and backend architecture. I also became proficient in using the Google Places API and deploying Firebase Functions.

## Future plans
I aim to expand search options, allowing users to refine their preferences even further. Additionally, I plan to implement a login feature, enabling users to keep track of restaurants they've visited. User feedback will continue to shape future improvements.
